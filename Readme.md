# Student Management System

A simple **Student Management System built using Python**.  
This project is a console-based application that allows users to manage student records using a menu-driven interface.

## 📌 Project Overview

The Student Management System provides basic operations for managing student information.

Users can:

- Add a new student
- View all student records
- Search for a student
- Update student marks
- Delete a student record
- Calculate a student's grade
- Exit the application

The project is developed using core Python concepts such as:

- Variables
- Data types
- Lists
- Dictionaries
- Functions
- Loops
- Conditional statements
- User input
- Basic CRUD operations

## ✨ Features

### 1. Add Student

Allows the user to add a new student by entering:

- Student name
- Registration number
- Branch
- Marks

The student information is stored in a list using a Python dictionary.

### 2. View Students

Displays all student records currently stored in the system.

### 3. Search Student

Allows users to search for a student using their registration number.

### 4. Update Student

Allows users to update the marks of an existing student using their registration number.

### 5. Delete Student

Allows users to remove a student record from the system using their registration number.

### 6. Calculate Grade

Calculates the student's grade based on their marks.

| Marks | Grade |
|-------|-------|
| 90 and above | A+ |
| 80 - 89 | A |
| 70 - 79 | B |
| 60 - 69 | C |
| 50 - 59 | D |
| Below 50 | F |

### 7. Exit

Allows the user to safely exit the application.
